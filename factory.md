# Factory Configuration — IdeaFlow

## Project

- **name**: IdeaFlow
- **type**: iOS + watchOS app
- **language**: Swift 6.1, SwiftUI

## Eval Dimensions

- **tests**: Unit and integration test pass rate
- **lint**: SwiftLint violations (warnings and errors)
- **type_check**: Swift compilation success
- **capability_surface**: Feature completeness (voice capture, Claude processing, Obsidian export)
- **observability**: Structured logging coverage

## Surfaces

### Modifiable (mutable_surfaces)

All files in these patterns can be modified by factory agents:

- `*.swift` — Swift source files
- `*.yml` — XcodeGen project configuration
- `*.md` — Documentation
- `*.sh` — Build and eval scripts
- `*.plist` — Info.plist and entitlements
- `eval/*.py` — Eval harness

### Fixed (fixed_surfaces)

Do not modify:

- `.factory/` — Factory system files
- `*.xcodeproj/` — Generated by XcodeGen, do not edit directly
- `*.xcworkspace/` — Generated, do not edit
